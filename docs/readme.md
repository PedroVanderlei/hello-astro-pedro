# Notas de Rodapé

**Notas de Rodapé** é um projeto de escrita, estudo e publicação de longo prazo, orientado pela seriedade intelectual, pela formação teológica e pela recusa de superficialidade.

Este repositório contém o código do site, mas também documenta — de forma explícita — os **princípios editoriais, éticos e estruturais** que governam o projeto.

O site não existe como blog reativo, nem como diário pessoal, nem como plataforma de opinião rápida. Ele existe como **espaço de pensamento amadurecido**, ainda que em processo.

---

## 1. O que é este projeto

O **Notas de Rodapé** é:

- um espaço de textos densos e ensaísticos;
- um repositório de reflexões teológicas, éticas e conceituais;
- uma base de amadurecimento intelectual para produção acadêmica futura;
- um ambiente que privilegia clareza, tempo e responsabilidade.

O site publica **apenas material maduro**, mesmo quando provisório, e mantém todo o processo cru fora do espaço público.

---

## 2. O que este projeto não é

Este projeto **não é**:

- um blog de opinião pessoal;
- um site de notícias;
- uma plataforma de militância política;
- um espaço devocional;
- um substituto de igreja, comunidade ou formação institucional;
- um experimento técnico orientado por tendências.

Essas exclusões são decisões conscientes, documentadas e mantidas ao longo do tempo.

---

## 3. Estrutura documental do repositório

Este repositório contém uma pasta de documentação que **funciona como constituição do projeto**.  
Esses documentos devem ser lidos **antes de qualquer modificação significativa**.

### Documentos fundamentais

- `reader-assumptions.md`  
  Define para quem o site escreve, quem ele acolhe e quem ele não tenta reter.

- `content-maturity-and-revision.md`  
  Define o que pode ser publicado, quando, como e em que estágio de maturidade.

- `authority-and-voice.md`  
  Define o tom, a posição de fala e o tipo de autoridade exercida pelo site.

- `non-goals-and-limits.md`  
  Define explicitamente o que o projeto não tenta ser ou fazer.

- `seo-and-visibility.md`  
  Define a função do SEO, seus limites éticos e sua relação com o conteúdo.

- `99-ai-instructions.md`  
  Documento constitucional que define como agentes de IA devem atuar neste projeto.

Esses arquivos **não são acessórios**.  
Eles são **normativos**.

---

## 4. Relação entre código e conteúdo

O código existe para **servir a forma do conteúdo**, não para determiná-la.

Decisões técnicas devem:

- preservar a lentidão deliberada do site;
- evitar abstrações prematuras;
- manter a arquitetura simples e estável;
- respeitar os princípios editoriais já documentados.

Mudanças técnicas **não devem contradizer decisões conceituais**.

---

## 5. Uso de IA neste projeto

Este projeto utiliza IA como ferramenta auxiliar, **não como coautora**.

Agentes de IA devem:

- respeitar todos os documentos fundacionais;
- nunca assumir intenções não explicitadas;
- perguntar antes de decidir;
- preservar coerência de longo prazo;
- alertar quando uma solicitação violar limites do projeto.

O documento `99-ai-instructions.md` tem precedência sobre qualquer sugestão automatizada.

---

## 6. Horizonte de longo prazo

O **Notas de Rodapé** é pensado em horizonte de **4+ anos**, com:

- produção acadêmica honesta;
- amadurecimento teológico progressivo;
- possíveis artigos, TCC e pesquisas formais;
- constância sem aceleração artificial.

O projeto aceita revisão, amadurecimento e correção como virtudes.
